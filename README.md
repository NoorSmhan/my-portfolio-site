# My Portfolio Site

This is my personal portfolio website built as part of my Front End Web Developer Nanodegree.

It was created using HTML, CSS, and JavaScript, and it highlights my front-end skills through a clean layout and interactive features.

## Features

- Responsive design
- Interactive elements using JavaScript
- Project showcase section
- Clean and simple user interface

## Tools Used

- HTML
- CSS
- JavaScript

## What I Learned

While building this project, I practiced working with the DOM, adding interactivity with JavaScript, and organizing a front-end project in a clear way.

## How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser
